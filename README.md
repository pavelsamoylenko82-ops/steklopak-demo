# СтеклоПак Торг - демо-лендинг производителя ПВХ-окон

Одностраничный лендинг производства окон ПВХ в Молодечно (Минская, Гродненская, Витебская,
Брестская области). Vite + Tailwind CSS + чистый JS, без фреймворков. Сборка рассчитана на
GitHub Pages в подпапке: в `vite.config.js` стоит `base: './'`, все пути относительные.

## Что внутри

- `src/data/company.js` - единственный источник фактов: название, телефоны, адреса, график,
  реквизиты, профили, стеклопакеты, армирование, гарантии, география, отзывы, фото.
- `src/js/render.js` - разметка секций из данных.
- `src/js/quiz.js` - пошаговый опросник на 4 шага с валидацией и маской телефона.
- `src/js/gallery.js` - лайтбокс (крестик, фон, Esc, возврат фокуса).
- `src/js/header.js` - мобильное меню.
- `src/style.css` - дизайн-система: 5 цветов, Manrope + Golos Text, чертёжные линии и метки.
- `src/fonts/` - woff2 из Google Fonts (кириллица и латиница), без внешних запросов.
- `public/img/` - WebP, собранные из фото клиента скриптом `tools/convert-images.py`.
- `tools/check.mjs` - Playwright-проверка: консоль, изображения, переполнение, квиз, лайтбокс.
- `tools/section-shot.mjs` - секционные скриншоты для визуального контроля.

## Источник данных

Только `Клиенты/СтеклоПак Торг/ДАННЫЕ.md` (Яндекс Карты и архивные копии сайта steclopak.by).
Оригиналы фото в `Клиенты/СтеклоПак Торг/assets/` не изменялись: скрипт конвертации только
читает их и пишет WebP в `public/img/`.

Ограничения соблюдены: цен нет, сроков изготовления в днях нет, телефоны и отзывы - из данных,
фото из `assets/`, сервис `ok.ru/oknamolo` не использован (другой бренд).

## Локальный запуск

```bash
cd D:\учеба\PVL\Проекты\steklopak-demo
npm install
npm run dev
```

Проверка собранной версии (как на хостинге):

```bash
npm run build
npm run preview
# открыть http://localhost:4173/
```

Сборка и все проверки одной командой:

```bash
npm run build
node tools/check.mjs http://localhost:4173/    # скриншоты + консоль, img, overflow, квиз, лайтбокс
node tools/check-mobile.mjs http://localhost:4173/   # 320px, бургер-меню, якорь
node tools/check-subpath.mjs                    # сборка в подпапке /steklopak-demo/
```

Скриншоты сохраняются в `tools/shots/`.

## Выкладка на GitHub Pages

Вариант 1, автоматически через Actions (файл `.github/workflows/deploy.yml` уже в проекте):

```bash
git init
git add .
git commit -m "СтеклоПак Торг: демо-лендинг"
git branch -M main
git remote add origin https://github.com/<логин>/steklopak-demo.git
git push -u origin main
```

Затем в GitHub: Settings - Pages - Source: **GitHub Actions**. Сайт откроется по адресу
`https://<логин>.github.io/steklopak-demo/`. `base: './'` уже учитывает подпапку.

Вариант 2, руками из dist/ в ветку `gh-pages`:

```bash
npm run build
npx gh-pages -d dist --message "deploy: СтеклоПак Торг"
```

Или просто скопировать содержимое `dist/` в корень ветки `gh-pages`:

```bash
git subtree push --prefix dist origin gh-pages
```

GitHub Pages: Settings - Pages - Source: Deploy from a branch - `gh-pages` / root.

## Важно

- На странице стоит `<meta name="robots" content="noindex, nofollow">`. На боевом домене клиента
  его нужно заменить на `index, follow`.
- Отправка заявки намеренно без бэкенда: после четвёртого шага показывается карточка с
  параметрами и честная пометка про Telegram. Форма ничего никуда не отправляет.
- Изображения в `public/img/` сгенерированы из фото клиента; для боевой версии желательно
  заменить снимок производственной линии на более крупный оригинал.
