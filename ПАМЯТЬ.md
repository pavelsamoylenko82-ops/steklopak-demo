## 2026-11-23 - слой анимаций на GSAP + Lenis, 3D-поворот окна убран

Бэкап до правок: коммит `33d6ebb backup: before gsap-lenis motion fix`.

- **Движок:** `motion` удалён, добавлены `gsap` 3.15.1 и `lenis` 1.3.27. Теперь один движок на весь сайт, квиз тоже на GSAP.
- **Hero:** сломанный `rotateY(0 -> -88deg)` и накладная створка с переплётами удалены. Левый столбец (метка, H1, абзац, кнопки, 4 факта) появляется `y 22 -> 0`, `opacity 0 -> 1`, stagger 0.07, 0.65s `expo.out`. Фото раскрывается `clip-path inset(0 0 100% 0 round 24px) -> inset(0 0 0% 0 round 24px)` за 0.8s, картинка доезжает `scale 1.12 -> 1.02`. Маска запускается по `load` фото, но не позже 400 мс.
- **Скролл в Hero:** кадр не крутится, внутри ровной рамки `rounded 24px` обёртка едет `yPercent -4 -> 6` и `scale 1.02 -> 1.08` (scrub 0.6). Обёртка `.window-photo-wrap` с `inset: -10% 0`, поэтому край кадра не вылезает.
- **Lenis:** только при `min-width: 1024px` + `hover: hover` + `pointer: fine` и не при reduced-motion. Синхронизация: `lenis.on('scroll', ScrollTrigger.update)`, `gsap.ticker.add(lenis.raf)`, `gsap.ticker.lagSmoothing(0)`. Якоря шапки и CTA перехватываются и скроллятся через `lenis.scrollTo` без своего offset: Lenis сам учитывает CSS `scroll-padding-top`, иначе отступ применяется дважды и секция встаёт на 82 px выше. Лайтбокс: `body.no-scroll` останавливает инерцию через MutationObserver.
- **ScrollTrigger:** появление секций и карточек через `ScrollTrigger.batch(... once: true, start: 'top 86%', stagger 0.08)`; в производстве параллакс фото линии `yPercent -5 -> 5` + bento `y 24 -> 0` stagger 0.08; квиз `x ±18 -> 0`, opacity, 0.35s `power2.out`.
- **Начальные состояния** (`opacity`, `transform`, `clip-path`) ставит только GSAP: класс `.js-motion .reveal` больше не прячет контент через CSS, поэтому при падении JS страница остаётся читаемой. Плюс страховка: после остановки скролла элементы, проскочившие старт триггера, показываются сразу, зависания в `opacity: 0` нет. `ScrollTrigger.refresh()` на `load` и после `document.fonts.ready`.
- **prefers-reduced-motion:** Lenis не создаётся, GSAP не стартует, CSS принудительно ставит `opacity: 1`, `transform: none`, `clip-path: none`.
- **Проверка:** `npm run build` (`base: './'` на месте), один финальный прогон `node tools/check.mjs` на 320/360/390/768/1024/1280/1440: 0 ошибок консоли и страницы, 0 переполнения, 9/9 картинок, квиз 4 шага и сброс, лайтбокс. Скриншоты `tools/shots/hero-1440.png`, `hero-photo-360.png` (рамка 24px, фото ровное, `clip-path: none`), секции 360.
- **Откат:** `git reset --hard 33d6ebb` (или `git checkout 33d6ebb -- Проекты/steklopak-demo`), затем `npm install` и `npm run build`.

## 2026-11-23 - старт демо-лендинга «СтеклоПак Торг»

Задача: один проход, чистый визуально сильный демо-лендинг производителя ПВХ-окон (Молодечно, 4 области), готовый к GitHub Pages. Источник фактов только `Клиенты/СтеклоПак Торг/ДАННЫЕ.md`.

### Intake (4 строки)

1. **ICP и контекст:** владельцы квартир и частных домов в Молодечно и четырёх областях РБ, 30-60 лет, открывают сайт с телефона вечером или с улицы, сравнивают 3-5 оконных фирм, ищут завод напрямую без наценки посредников.
2. **Главное действие:** оставить заявку на индивидуальный расчёт через пошаговый опросник (второй по важности - звонок).
3. **Топ-3 возражения:** «переплачу посредникам», «сорвут сроки и не приедут по гарантии», «а вы вообще работаете в моём районе».
4. **Реальные факты:** своё производство в Молодечно с 2009 года; профили ENWIN, ARTEK, PROPLE, KBE, Salamander, Grunhaus; стеклопакеты 1- и 2-камерные, энергосберегающие, стекло 4 мм; армирование от 1,5 мм; гарантия 5 лет на изделия и 3 года на монтаж; монтаж по СТБ и ГОСТ; Минская, Гродненская, Витебская, Брестская области; 4,2 из 5 на Яндекс Картах (12 оценок, 9 отзывов); Пн-Пт 09:00-17:30; +375 29 518-01-60, +375 29 618-01-80, +375 (176) 53-07-77; офисы на ул. Толстого, 10 и ул. В. Гостинец, 143Б, оф. 309. Цен нет - только индивидуальный расчёт.

### Дизайн-план

Три направления из мира бизнеса:
1. **Архитектурный чертёж** - лист с тонкими размерными линиями, метками +, спецификацией. Помогает действию: показывает инженерную точность и «мы производим сами», а не продаём перекупленное.
2. **Заводской цех** - крупные промышленные кадры, графит и оранжевый станок, ощущение производства. Помогает доверию, но легко скатывается в «промышленный шаблон».
3. **Каталог оконной компании** - каталог с прайс-строками и фото объектов. Не подходит: цен нет, а каталог без цен провисает.

Выбрано: **архитектурный чертёж + заводской кадр в графитовом блоке**. Производство подаётся как инженерная спецификация: тонкие линии 1px, угловые размерные метки вокруг фото, контурные SVG-схемы конструкций в шагах опросника.

- **Палитра:** фон #F3F5F7, карточки #FFFFFF, рамки #D8E0E8, графит #0F172A, текст #1E293B / #526071, акцент #0369A1 (hover #075985).
- **Типографика:** Manrope 600/700/800 (заголовки, трекинг -0.025em) + Golos Text 400/500/600 (текст, табличные цифры). Шрифты самохостed в public/fonts (woff2, кириллица + латиница), без внешних запросов.
- **Композиция:** асимметрия: hero 55/45, графитовая секция фото слева / таблица справа, bento-галерея 12 колонок с блоками 4/3/5 и 3/3/6.
- **Фирменный приём:** чертёжная рамка с угловыми метками «+» и короткими выносками-размерами у фото; контурные SVG-схемы окон stroke 1.5.
